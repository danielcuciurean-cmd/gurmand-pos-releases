Gurmand TV – administrare afișaj

1. Cheie de acces GitHub

O lipești o singură dată, rămâne salvată doar în browserul acesta. Nu o trimite nimănui. Cum o faci: GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate. Repository access: doar gurmand-pos-releases; Permissions → Contents: Read and write.

3. Imagini

Folosește PNG sau JPG 1366×768 (16:9). Pozele noi se adaugă la sfârșit; apoi le muți cu ◀ ▶ și apeși „Salvează ordinea”.

Televizorul se actualizează singur în 2–4 minute după salvare.
