Gurmand TV – administrare afișaj

1. Cheie de acces GitHub

O lipești o singură dată, rămâne salvată doar în browserul acesta. Nu o trimite nimănui. Cum o faci: GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate. Repository access: doar gurmand-pos-releases; Permissions → Contents: Read and write.

3. Imagini

Alegi pozele (se adaugă la sfârșit, marcate cu galben), le muți cu ◀ ▶, ștergi ce nu mai vrei, iar la final apeși Publică: totul pleacă într-o singură operație, deci o singură publicare. Folosește JPG sau PNG 16:9 (ex. 1366×768).

Ai modificări nepublicate. Apasă „Publică” ca să ajungă pe televizor.
Televizorul se actualizează singur la câteva minute după publicare.
